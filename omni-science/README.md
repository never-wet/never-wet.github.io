# Omni-Science

Next-generation science learning platform that combines structured knowledge, guided learning paths, and interactive 3D simulations.

## Features
- **Knowledge Explorer:** Search and explore scientific concepts with structured data.
- **Learning Path System:** Guided curriculum from Basic to Scientist level.
- **Intuition Engine:** Toggle between Theory, Visual (3D), and Analogy explanations.
- **Interactive 3D Visualizations:** Warped spacetime gravity labs and entropy simulations.

## Tech Stack
- **Framework:** Next.js
- **Styling:** Tailwind CSS + Framer Motion
- **3D Engine:** React Three Fiber (Three.js)
- **State:** Zustand
- **Math:** KaTeX

## Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to see the result.
